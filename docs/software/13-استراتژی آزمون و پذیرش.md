# استراتژی آزمون و پذیرش

شناسه: FL-SW-13 | نسخه ۱.۰ | وضعیت: نسخه عملیاتی نرم‌افزار با ثبت دستی؛ اتصال صنعتی و پذیرش میدانی در انتظار اجرای پایلوت

## گیت نرم افزاری اجراشده

روی VPS از commit دقیق: نصب frozen، TypeScript، build Vite و node --test server/app.test.mjs. سه سناریوی یکپارچه موفق شامل ماتریس هشت نقش، احراز هویت و محافظت درخواست، اعتبارسنجی/نسخه/تأیید مستقل و ابطال نشست/محدودیت تلاش است.

## تست API

ناشناس workspace نگیرد؛ Origin و CSRF غلط رد شوند؛ نقش بدون write نتواند مستقیم ایجاد کند؛ good > total و readingEnd < readingStart رد شوند؛ version قدیمی ۴۰۹؛ سازنده نتواند تأیید کند؛ approved تغییر نکند؛ رمز موقت مسیر تغییر اجباری داشته باشد.

## گیت استقرار

Nginx syntax، manifest SHA و فایل نسخه، API health هم‌نسخه، HTTPS و redirect، logo و دارایی اصلی موجود، مسیر فایل مخفی و asset ناموجود بسته، دسترسی ناشناس ۴۰۱. سلامت مسیر عمومی مساوی پذیرش عملیات واقعی کارخانه نیست.

## UAT پیشنهادی

دو کاربر واقعی مجزا یک شیفت را ثبت و تأیید کنند؛ بازرس اندازه مرجع و عدم انطباق را ثبت کند؛ مدیر خروجی CSV و تطبیق شاخص را بررسی کند؛ حساب غیرفعال فوراً از دسترسی بیفتد؛ تست روی نمایشگر خط و موبایل و کیبورد انجام شود. شاهد شامل رکورد، زمان، نقش و صورت‌جلسه باشد.

## گیت های باز

تست بار، پنتست مستقل، بازیابی بکاپ خارج سایت، مرورگر تمام نقش‌ها، صحه‌گذاری ابزار، دیتاست و دقت مدل در کارخانه هنوز پذیرش مستقل می‌خواهند. PASS کد جای این گیت‌ها ثبت نمی‌شود.
