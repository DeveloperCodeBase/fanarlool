# ماتریس ردیابی و بسته تحویل

شناسه: FL-SW-18 | نسخه ۱.۰ | وضعیت: نسخه عملیاتی نرم‌افزار با ثبت دستی؛ اتصال صنعتی و پذیرش میدانی در انتظار اجرای پایلوت

## نیاز به کد

FR-01/02: server/app.mjs و server/domain.mjs؛ FR-03/04: schema و validateRecord و مسیر records؛ FR-05: audit در app/storage؛ FR-06: users/admin؛ FR-07: src/platform/api.ts؛ FR-08: productionKpis در domain. رابط: src/App.tsx و PublicLanding.tsx و platform.css.

## نیاز به آزمون

server/app.test.mjs سناریوهای احراز هویت، مجوز، CSRF، داده، نسخه، تأیید مستقل و نشست را پوشش می‌دهد. scripts/vps.sh و remote.ps1 گیت release، manifest، backup و health را اجرا می‌کنند. QA مرورگر، بار، بازیابی و پذیرش صنعتی شواهد جدا می‌خواهند.

## نیاز به سند

پروپوزال‌های fanar-proposal و fanarlool-proposal2-1 منشأ کاربردهای کیفیت، تولید، تجهیزات و انرژی‌اند. منشور ۰۱ مرز تحویل؛ SRS ۰۳ قواعد؛ معماری ۰۴؛ API ۰۶؛ امنیت ۰۸؛ پایلوت ۱۰؛ AI ۱۱؛ پذیرش ۱۳؛ استقرار ۱۴؛ DR ۱۵ و برنامه ۱۷ مسیر اجرایی را مشخص می‌کنند.

## شواهد تحویل

نسخه پایه این مجموعه 99f5770c43ac914f743de09196cb174352dcf49b است. validation و deploy روی VPS موفق گزارش شده‌اند. دامنه fanarlool.vistapower.ir، API روی Unix socket و بدون پورت جدید. داده واقعی کارخانه و گواهی میدانی هنوز ارائه نشده؛ حساب اولیه باید توسط مالک فعال شود.
